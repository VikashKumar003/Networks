BASIC NETWORK COMMANDS IN WINDOWS
1)ipconfig
  ->IPv4 Address (your device’s IP address on the network),IPv6 Address (if enabled),Subnet Mask, Default Gateway, DNS Servers, MAC Address (with extra flag)

2)ipconfig/all
  ->Detailed info (MAC, DHCP, DNS, Lease time, etc.)

3)ipconfig/displaydns
  ->Shows current DNS cache entries. It will delete automatically and can be deleted manually as well.

4)ipconfig /flushdns 
  ->Clears DNS cache(Manual way).

5)arp -a
  ->display the ARP table of your computer.

6)nslookup
  ->It lets you find the IP address for a domain name or the domain name for an IP address.
  ->Ex: if you type google.com it will show the IPv4 and IPv6 address of google.com.

7)ping <ip address>
  ->check if your computer can reach another device (host) over the network.
  ->It works by sending ICMP Echo Request packets and waiting for ICMP Echo Reply packets.

8)tracert <IP address>
  ->Shows the path your packet takes across routers (hops) to reach the destination.
  ->Useful for finding where delays or failures occur.

9)pathping <IP address>
  ->Combines ping + tracert.
  ->First traces the route, then pings each hop multiple times to show packet loss and latency at each hop.

10)netstat
  ->Shows active network connections and listening ports.
  ->Useful for checking what apps are using the network.
